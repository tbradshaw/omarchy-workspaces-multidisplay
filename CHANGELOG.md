# Changelog

## 0.1.0 (unreleased)

- Initial release, based on Omarchy 4.0.4's `omarchy.workspaces` widget.
- Each bar marks the workspace shown on its own monitor.
- Workspaces shown on other monitors get an outlined marker.
- A thin line in the bar's text colour shows which monitor each workspace is on,
  placed by the monitor layout, dimmed unless the workspace is visible.
- Tooltips name each workspace's monitor and position.
- Refresh monitor state after workspaces move between monitors.
